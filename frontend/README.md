# 📋 Sistema de Registro de Presença

Sistema web desenvolvido para facilitar o **registro e acompanhamento da presença de colaboradores** em ambientes corporativos.

A aplicação permite que o funcionário informe sua matrícula para realizar o registro, exibindo informações como nome, horário e situação da presença.

🔗 **Acessar o projeto:** https://sistemadepresenca.netlify.app

---

## 🚀 Funcionalidades

* 🔢 Registro de presença através da matrícula
* 👤 Identificação do funcionário
* 🕐 Registro do horário de entrada
* 📋 Visualização dos registros de presença
* 📊 Acompanhamento da situação da presença
* 💻 Interface adaptada para computadores
* 📱 Interface adequada para utilização em tablets
* 🔗 Integração entre frontend e backend

---

## 🖥️ Demonstração

O sistema foi desenvolvido pensando em ambientes onde os colaboradores podem utilizar um computador ou tablet para realizar o registro de presença de forma rápida e simples.

### Fluxo principal

```text
Funcionário
     ↓
Informa a matrícula
     ↓
Sistema identifica o funcionário
     ↓
Registro da presença
     ↓
Horário é registrado
     ↓
Informações ficam disponíveis para acompanhamento
```

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/brunavillanova/sistema-presenca-backend.git
```

### 2. Acesse a pasta do projeto

```bash
cd sistema-presenca-backend
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o servidor

```bash
npm start
```

O backend será iniciado localmente.
